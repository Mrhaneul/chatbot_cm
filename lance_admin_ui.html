Add Content to Lance

Use this tool to add new FAQ answers or platform instructions to Lance. The tool will save the file, update the search index, and optionally upload one or more PDF guides — all in one step.

Before you start: Make sure the Lance backend is running on this machine (uvicorn app.main:app) and you are accessing this page at http://localhost:8000/admin. Changes take effect immediately after submission.

    Select a file to archive from Lance. The search index will be rebuilt automatically and its Firestore PDF guide mappings will be cleaned up. A timestamped copy will be kept in the content archive.
