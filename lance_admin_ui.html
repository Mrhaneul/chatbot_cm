Add Content to Lance

Use this tool to add new FAQ answers or platform instructions to Lance. The tool will save the file, update the search index, and optionally upload a PDF guide — all in one step.

Before you start: Make sure the Lance backend is running on this machine (uvicorn app.main:app) and you are accessing this page locally. Changes take effect immediately after submission.
