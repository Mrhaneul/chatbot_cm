RDP (Remote Desktop Protocol) lets you connect to and control another Windows computer remotely. Here's how to use it:
On the computer you want to connect TO:

Enable Remote Desktop:

Right-click "This PC" → Properties → Remote Desktop
Toggle "Enable Remote Desktop" to ON


Note the computer's IP address (run ipconfig in Command Prompt)

On the computer you're connecting FROM:

Search for "Remote Desktop Connection" (or mstsc in Run dialog)
Enter the target computer's IP address or hostname
Click "Connect"
Enter your username and password when prompted
