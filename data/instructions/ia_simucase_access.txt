PROBLEM:
Student is opted into Immediate Access but cannot access their SimuCase simulation platform or needs help redeeming their access code.

APPLIES TO:
Courses using the SimuCase simulation platform (commonly used in Social Work courses such as SWK 335 Substance Use Disorders, Treatment, Recovery).

CANVAS LOCATION:
Course Navigation > Immediate Access

STEP-BY-STEP RESOLUTION:
1. Login to Canvas and select the course that is using the SimuCase platform.
   - This example uses SWK 335, but the same steps apply to any course using SimuCase.
2. Click → Immediate Access from the left-hand side pane.
3. Click → Reveal Access Code
4. Open a new browser and Copy the publisher’s URL appearing under → More Info. Then, paste the URL in the new browser to create your SimuCase account.
5. Click → Accept All, then proceed to create your account by filling in the questions that appear on the screen, then click → Continue.
6. Next, enter the code from Canvas into the field → Promo Code, then click → Apply.
   - You should then be able to access your SimuCase material.

IMPORTANT NOTES:
- Your access code functions as a Promo Code on the SimuCase payment page.
- The code covers your membership cost through Immediate Access.
- Do not select a paid membership option - use your Promo Code instead.

EXPECTED RESULT:
After applying your promo code, you should have full access to the SimuCase simulation materials for your course.

IF ISSUE PERSISTS:
Contact ImmediateAccess@calbaptist.edu for assistance. If possible, include a screenshot of what you are seeing.
